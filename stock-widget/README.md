# 行情小窗

macOS 桌面透明自选行情悬浮小窗。无边框、置顶、可调背景浓度、鼠标穿透、老板键，菜单栏常驻上证指数；自选支持手动搜索添加，或扫码登录东方财富后自动同步账号内**全部自选分组**。

个人自用工具：数据来自东方财富 / 腾讯公开网页接口（非官方），仅供个人参考，不提供任何交易功能。

## 运行

```bash
cd stock-widget
npm start          # 需已执行 npm install
```

首次启动有三步引导（选模式 → 加自选 → 调外观），随时可跳过。

## 常用操作

| 操作 | 方式 |
|---|---|
| **调整大小** | **拖窗口任意边缘**；默认开启**宽高双自适应内容**（宽度始终紧贴最宽一行，无空隙；高度贴齐行数）——手动拖拽后自动切手动尺寸，设置里可重开 |
| **透明度（背景浓度）** | **右键小窗空白处 → 背景浓度**（35–100% 五档）或眼睛面板滑杆；浓度 <55% 时自动关毛玻璃获得最大通透，≥55% 恢复磨砂质感 |
| **空白处右键** | 背景浓度 / 涨跌幅排序 / 迷你条 / 立即隐身 / 设置 —— 最快入口 |
| **切换分组** | **点标题栏分组名（如「自选股 384 ▾」）**：弹出全部自选分组列表，与东财账号里的分组一一对应；也可选「全部（合并视图）」；全局快捷键 **⌥⇧←/→** 循环切分组（不用碰鼠标） |
| **持仓列** | 设置 → 数据与自选 → 持仓列表：粘贴你的持仓股（每行「代码 成本 [数量]」，成本可选），小窗出现独立「持仓」分组显示实时行情。真实持仓需在买卖后手动回这里更新——东财交易账户的持仓需要交易级登录，办公机上不该碰 |
| **排序** | 眼睛面板或右键菜单 → 排序：默认（自选顺序）/ 涨幅↓ / 跌幅↓ / 价格 高→低 / 价格 低→高；持仓列按盈亏参与排序；设置 → 排序方式同款 |
| **异动提醒** | 自动：自选涨跌幅越过阈值（默认 ±5%）提醒，每只每方向每日仅一次。三种提醒方式可选：**系统通知**（横幅）/ **菜单栏信号 ▲▼**（最低调，只在右上角「沪…」旁标一个三角）/ **静默**（仅小窗内黄条）；「低调通知」选项下标题正文不出现股票名与价格。窗口开着时一律用小窗内黄条（零暴露）；**隐身/会议期间提醒自动静默累积，唤回小窗后一次性展示**。设置 → 涨跌提醒可改阈值/方式/关闭 |
| **防录屏保护** | 开启后窗口不出现在截屏 / 录屏 / 屏幕共享里（macOS 内容保护）——开会共享屏幕也安全；设置 → 行为或托盘菜单可开 |
| **收盘战报** | 自动：交易日 15:05 一条通知，汇总自选平均涨跌、涨跌家数、领涨领跌 |
| **全屏可见** | 小窗在所有工作区/全屏应用之上可见——上班用全屏应用时也在 |
| **切换分组** | **点标题栏分组名（如「自选股 384 ▾」）**：弹出全部自选分组列表，与东财账号里的分组一一对应；默认落在第一个分组（自选股），也可选「全部（合并视图）」（去重后 422 只） |
| 添加自选 | 标题栏 🔍 → 搜索「茅台 / 600519 / AAPL」回车 |
| 批量导入 | 设置 → 手动列表 → 粘贴或从 .txt / .ebk 文件导入 |
| 云端同步 | 设置 → 云端自选 → 扫码登录（60 秒轮询，手机上改自选自动跟上） |
| 分时图 | 单击行情行，原地展开 / 收起（黄虚线为当日均价线，现价在其上方=强） |
| 拖拽排序 | 按住行拖动（云端模式仅本地顺序，增删以云端为准）；拖到屏幕边缘 ≤14px 自动贴边吸附 |
| **键盘流** | **↑/↓** 选中行、**Enter** 展开分时、**⌘F** 聚焦搜索添加——全程不用碰鼠标 |
| **仅看置顶** | 右键空白处或眼睛面板开关：只显示置顶的自选（手动模式；自选几百只时快速聚焦） |
| 右键菜单 | 复制代码 / 在东财打开 / 置顶 / 删除 |
| 开机自启 | 设置 → 行为：上班开机即有，省掉"手动开应用"这个动作 |
| 迷你条 | 双击标题栏，或眼睛图标 → 形态；迷你条下点眼睛图标恢复完整 |
| **退到后台** | **标题栏 — 按钮、⌘M / ⌘W**：窗口隐藏但行情继续刷新；恢复 = 点 Dock 图标（深色圆角方块、红绿双蜡烛图标）；首次会弹系统通知引导 |
| **退出应用** | **标题栏 ✕ 按钮（最右）**：3 秒内连点两次才彻底结束进程（防误触杀掉行情；托盘/Dock 一并关闭），不是退到后台；也可用菜单栏/Dock 菜单的「退出行情小窗」 |
| 像普通应用 | 默认开启：Dock 有图标、⌘Tab 可切换、点 Dock 恢复；需要隐蔽时可在设置或托盘菜单关闭（仅菜单栏托盘可见） |
| 菜单栏指数 | 状态栏常驻「沪3797 -0.4%」；若你装了 Ice/Bartender 类菜单栏管理器，可能被收进折叠区（在管理器里设为始终显示即可），不影响 Dock 恢复路径 |
| **老板键** | ⌥⇧H，或眼睛图标 → 立即隐身（可在设置改为完全隐藏）。隐身时**设置窗/登录窗一并隐藏**；主窗已藏时再按老板键会继续藏设置窗/登录窗而不是唤回主窗。完全隐藏模式下退出后重启仍保持隐身，菜单栏快捷键唤回 |
| 鼠标穿透 | ⌥⇧X 或眼睛图标（开启后窗口不再响应鼠标，恢复有四条路：⌥⇧X / **⌘Tab 切回应用后按 Esc** / **右键 Dock 图标 → 关闭鼠标穿透** / 托盘菜单；穿透期间窗口内会常驻黄色提示条写明这些方法） |
| **会议模式** | **⌥⇧M**（可改键），或托盘/右键菜单：一键隐身 + 防录屏 + 提醒静默 + 菜单栏文字清空（共享屏幕连菜单栏一起被录）；散会再按一次，恢复进会前状态并展示错过的提醒 |
| 显示/隐藏股票代码 | 默认隐藏（隐蔽优先）；右键空白处 → 显示股票代码，或设置 → 外观 → 显示股票代码 |
| **快捷键复位** | 设置 → 行为 → 全局快捷键 → **恢复默认快捷键**（改乱了随时一键回退） |
| 静默优先 | 变动脉冲默认关闭（办公室里红绿闪烁太显眼）；想要动效去设置 → 外观 → 变动脉冲开启 |
| 背景浓度 | 眼睛图标滑杆，或 ⌥⇧↑ / ⌥⇧↓（35%–100%） |

所有快捷键可在设置中重新录制；与其他应用冲突时会弹提示。所有可视操作均有对应的界面按钮，不依赖快捷键记忆。

## 开发

```bash
npm test           # 核心层单元测试（43 项）
npm run smoke      # 冒烟自检：真实拉数据 + 自动截图（--smoke 独立 profile，不污染日常配置）
npm run icon       # 重新生成托盘图标（纯 Node，无依赖）
WIDGET_DEV=1 npm start   # 打开 DevTools 调试渲染层
```

打包（需要时）：

```bash
npm install --save-dev electron-builder
npm run dist       # 产出 dist/行情小窗.dmg（arm64，LSUIElement：不驻 Dock）
```

## 架构

```
src/
├─ main/            # Electron 主进程
│  ├─ index.js      # 生命周期 · 单实例锁 · 崩溃重建 · 冒烟
│  ├─ window.js     # 主窗（透明分离置顶穿透位置记忆）+ 设置窗
│  ├─ login-window.js  # 扫码登录窗（独立 partition，探测式登录确认）
│  ├─ orchestrator.js  # 轮询状态机：备源切换 · 时段感知 · 快照 · 三分类失败
│  ├─ tray.js / shortcuts.js / ipc.js / logger.js / preload.js
├─ core/            # 零 Electron 依赖（可单测）
│  ├─ market/       # quote(东财) · tencent(备源) · search · trends · news
│  ├─ sync/myfavor.js  # 云端自选 API（分组列表 + 组内股票）
│  ├─ code-parser.js   # 全写法代码解析（A股/指数/ETF/北交所/港美股）
│  ├─ session.js       # 交易时段状态机（A/H/US）
│  └─ retry.js
├─ store/settings.js   # 原子写 + 双备份回滚
├─ renderer/        # 主窗 + 设置窗（无框架，零网络请求，全走 IPC）
└─ shared/constants.js
```

设计原则：网络与凭据全部收在主进程；渲染层零请求、零 Cookie 接触；云端自选**只读**（不在应用内增删云端，避免误覆盖手机端列表）。

## 可靠性设计

- **备源**：东财主源连续 3 次失败自动切腾讯（qt.gtimg.cn），主源恢复自动切回
- **时段感知**：竞价 / 连续竞价 / 午休 / 收盘 / 非交易日各用不同刷新频率；连续无变化自动降速（替代写死节假日表，自纠错）
- **失败三分类**：网络错误（退避重试）/ 登录过期（黄条 + 重扫按钮）/ 接口变更（通知 + 手动模式兜底），不会一律黄点
- **快照**：最后一份行情与自选本地留存，断网 / 崩溃重启后先恢复界面再拉新
- **存储**：写临时文件 + rename 原子落盘，保留 .bak 滚动备份，损坏自动回滚
- **日志**：按天滚动 7 天，Cookie / 凭据强制脱敏

## 已实测的接口（2026-10-12）

| 用途 | 端点 | 备注 |
|---|---|---|
| 批量行情 | `push2.eastmoney.com/api/qt/ulist/get` | ⚠️ `ulist.np` 已失效；必须带 `pn/pz/po/np/fid`，否则 rc:102 |
| 搜索 | `searchapi.eastmoney.com/api/suggest/get` | |
| 分时 | `push2his.eastmoney.com/api/qt/stock/trends2/get` | |
| 快讯 | `np-listapi.eastmoney.com/.../getNewsByColumns` | 必须带 `req_trace` |
| 云端自选 | `myfavor.eastmoney.com/v4/webouter/*` | 纯 Cookie + 固定 appkey；**必须带 cb 回调参数**（否则空 body）；**必须带 Referer**，且只能通过 `onBeforeSendHeaders` 注入（`referrer` 选项不生效、手动 `setHeader` 会被 Chromium 取消）；security 字段真实格式为 `市场号$代码$时间戳` |
| 备源行情 | `qt.gtimg.cn/q=` | GBK 编码 |

所有请求 UA / Referer 对齐东财网页版自身。接口参数以 `src/shared/constants.js` 为准，变更时只需改常量与对应适配器。
