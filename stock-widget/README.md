# 行情小窗

macOS 桌面透明自选行情悬浮小窗。无边框、置顶、可调背景浓度、鼠标穿透、老板键，菜单栏常驻上证指数；自选支持手动搜索添加，或扫码登录东方财富后自动同步账号内**全部自选分组**。

个人自用工具：数据来自东方财富 / 腾讯公开网页接口（非官方），仅供个人参考，不提供任何交易功能。

## 运行

```bash
cd stock-widget
npm start          # 需已执行 npm install
```

首次启动有三步引导（选模式 → 加自选 → 调外观），随时可跳过。

## 常用操作

| 操作 | 方式 |
|---|---|
| **调整大小** | **拖窗口任意边缘**；默认开启**宽高双自适应内容**（宽度始终紧贴最宽一行，无空隙；高度贴齐行数）——手动拖拽后自动切手动尺寸，设置里可重开 |
| **透明度（背景浓度）** | **右键小窗空白处 → 背景浓度**（35–100% 五档）或眼睛面板滑杆；浓度 <55% 时自动关毛玻璃获得最大通透，≥55% 恢复磨砂质感 |
| **空白处右键** | 背景浓度 / 涨跌幅排序 / 迷你条 / 立即隐身 / 设置 —— 最快入口 |
| **切换分组** | **点标题栏分组名（如「自选股 384 ▾」）**：弹出全部自选分组列表，与东财账号里的分组一一对应；也可选「全部（合并视图）」；全局快捷键 **⌥⇧←/→** 循环切分组（不用碰鼠标）；切换后列表自动回到最上方 |
| **持仓列** | 设置 → 数据与自选 → 持仓列表：粘贴你的持仓股（每行「代码 成本 [数量]」，成本可选），小窗出现独立「持仓」分组显示实时行情。真实持仓需在买卖后手动回这里更新——东财交易账户的持仓需要交易级登录，办公机上不该碰。**列表内直接增删**：右键任意股票 → 「加入持仓（本地记录）」填成本/数量；持仓分组里右键 → 「持仓成本 / 数量」改值、「从持仓删除」；持仓分组里点 🔍 搜索也是加持仓（同步提示补成本入口） |
| **排序** | 眼睛面板或右键菜单 → 排序：默认（自选顺序）/ 涨幅↓ / 跌幅↓ / 价格 高→低 / 价格 低→高；持仓列按盈亏参与排序；设置 → 排序方式同款；**排序按分组记忆**：每个分组（全部 / 持仓 / 各云分组）各自记住自己的排序，切分组自动恢复该组上次的排序（没动过 = 默认原序） |
| **异动提醒** | 自动：自选涨跌幅越过阈值（默认 ±5%）提醒，每只每方向每日仅一次。三种提醒方式可选：**系统通知**（横幅）/ **菜单栏信号 ▲▼**（默认，最低调，只在右上角「沪…」旁标一个三角）/ **静默**（仅小窗内黄条）；「低调通知」选项下标题正文不出现股票名与价格。**大盘指数异动**（上证/深成/创业板，默认 ±1.5%）用独立 ▲▲/▼▼ 双三角信号，可关；**提醒口径**可按「当日涨跌幅」或「持仓盈亏 %」判断（与持仓分组显示列一致）。窗口开着时一律用小窗内黄条（零暴露）；**隐身/会议期间提醒自动静默累积，唤回小窗后一次性展示**。设置 → 涨跌提醒可改阈值/方式/口径/关闭 |
| **个股预警（右键设置）** | 列表里右键个股 → 「预警设置…」（参考东财/同花顺）：六项可同时设——到价「涨到 ≥ / 跌到 ≤」+ 异动「涨幅超过 / 跌幅超过」%+ **急涨急跌**「N 分钟内涨超 / 跌超」%（分钟留空默认 5，时间窗从设置后开始采样，重启后重新积累不误报）；**持续有效**——每次越过条件在**屏幕底部弹出提醒条**（不夺焦点、点击打开小窗、可拖动到任意位置并记忆，提醒面板可预览，**显示时长可设**：设置 → 涨跌提醒 → 预警弹窗显示时间，3 秒至 1 分钟或不自动消失），回到条件内自动重新布防（**同一预警两次提醒之间有冷却间隔**，默认 15 分钟，设置 → 涨跌提醒 → 预警重复冷却可调——价位在阈值附近反复震荡时不会连弹，冷却期满后的真突破照常提醒），删除前一直有效；设了专属涨/跌幅的股票，该方向不再走全局异动阈值（另一方向不受影响）；预警中的股票不在当前分组也会照常拉行情监控；隐身/会议期间静默累积，唤回后展示 |
| **防录屏保护** | 开启后窗口不出现在截屏 / 录屏 / 屏幕共享里（macOS 内容保护）——开会共享屏幕也安全；设置 → 行为或托盘菜单可开 |
| **收盘战报** | 自动：交易日 15:05 汇总自选平均涨跌、涨跌家数、领涨领跌；随提醒方式分发——菜单栏信号/静默档不弹系统横幅（菜单栏给方向信号 + 小窗内黄条），横幅档才弹通知（低调模式下不出现股票名） |
| **全屏可见** | 小窗在所有工作区/全屏应用之上可见——上班用全屏应用时也在 |
| **切换分组** | **点标题栏分组名（如「自选股 384 ▾」）**：弹出全部自选分组列表，与东财账号里的分组一一对应；默认落在第一个分组（自选股），也可选「全部（合并视图）」（去重后 422 只） |
| 添加自选 | 标题栏 🔍 → 搜索「茅台 / 600519 / AAPL」回车；云端模式下会写回东财账号（合并视图落到默认分组，具体分组落到当前分组） |
| 批量导入 | 设置 → 手动列表 → 粘贴或从 .txt / .ebk 文件导入 |
| 云端同步（双向） | 设置 → 云端自选 → 扫码登录：手机 App / 网页里改自选自动跟上（60 秒轮询）；小窗里的添加 / 删除 / 拖拽顺序也写回东财（可在设置关闭恢复只读）。写回失败会黄条提示并回滚 |
| 分时图 | 单击行情行，原地展开 / 收起：黄虚线为当日均价线（现价在其上方=强），灰虚线为昨收，持仓股叠加蓝色成本线；标注当日最高 / 最低 / 振幅；展开后整行自动滚入可视区（窗口高度固定时也不会"点了没反应"），数据取不到时会写明"双源均无响应" |
| 拖拽排序 | 按住行拖动（云端模式下具体分组视图会把顺序写回东财；合并视图仅本地顺序）；右键可从自选删除（在多个分组时会列出来源）；拖到屏幕边缘 ≤14px 自动贴边吸附 |
| **键盘流** | **↑/↓** 选中行、**Enter** 展开分时、**⌘F** 聚焦搜索添加、**按住 ⌥** 临时显示股票代码（松开恢复隐藏）——全程不用碰鼠标 |
| **仅看置顶** | 右键空白处或眼睛面板开关：只显示置顶的自选（手动模式；自选几百只时快速聚焦） |
| 右键菜单 | 复制代码 / 在东财打开 / 预警设置（到价 + 异动 + 急涨急跌）/ 置顶 / 删除 |
| 开机自启 | 设置 → 行为：上班开机即有，省掉"手动开应用"这个动作 |
| 迷你条 | 双击标题栏，或眼睛图标 → 形态；迷你条下点眼睛图标恢复完整 |
| **列表滚动（手动触发）** | 默认不滚；**空白处右键 → 启动滚动**（或眼睛面板「列表滚动」）后列表缓慢下滚循环：约 1 秒一行、到底停 2 秒回顶重来；**鼠标移上去立即暂停，移开继续**；同入口「停止滚动」即停（运行态不跨重启记忆）；滚轮 / ↑↓ 手动滚动后暂停 4 秒再续 |
| **退到后台** | **标题栏 — 按钮、⌘M / ⌘W**：窗口隐藏但行情继续刷新；恢复 = 点 Dock 图标（深色圆角方块、红绿双蜡烛图标）；首次会以小窗内黄条引导（下次唤回时展示，不再弹系统通知） |
| **隐藏时暂停轮询** | 设置 → 行为 → 可选：窗口隐藏超 5 分钟自动暂停行情/云同步轮询（省电省流量；菜单栏加「·」滞后标记，点小窗或托盘立即恢复）。收盘后固定降为 15 分钟心跳（15:05 战报仍准时） |
| **退出应用** | **标题栏 ✕ 按钮（最右）**：3 秒内连点两次才彻底结束进程（防误触杀掉行情；托盘/Dock 一并关闭），不是退到后台；也可用菜单栏/Dock 菜单的「退出行情小窗」 |
| 像普通应用 | 默认开启：Dock 有图标、⌘Tab 可切换、点 Dock 恢复；需要隐蔽时可在设置或托盘菜单关闭（仅菜单栏托盘可见） |
| 菜单栏指数 | 状态栏常驻「沪3797 -0.4%」；若你装了 Ice/Bartender 类菜单栏管理器，可能被收进折叠区（在管理器里设为始终显示即可），不影响 Dock 恢复路径 |
| **状态栏** | 完整形态底部：左侧数据源与更新时间（**悬停状态点**看各状态合义），右侧**自选平均涨跌 + 涨跌家数**（涨红跌绿，单色模式自动中性）· 时段 · 数据源；**网络异常时点横幅立即重试**；悬停行情行可看完整名称与持仓明细（成本 / 数量 / 盈亏金额） |
| **老板键** | ⌥⇧H，或眼睛图标 → 立即隐身（可在设置改为完全隐藏）。隐身时**设置窗/登录窗一并隐藏，Dock 图标也临时藏掉**（⌘Tab 里不再出现「行情小窗」，唤回自动恢复）；主窗已藏时再按老板键会继续藏设置窗/登录窗而不是唤回主窗；会议模式中按老板键保持隐藏（不把窗口翻出来）。完全隐藏模式下退出后重启仍保持隐身（连 Dock 也不出现），菜单栏快捷键唤回 |
| 鼠标穿透 | ⌥⇧X 或眼睛图标（开启后窗口不再响应鼠标，恢复有四条路：⌥⇧X / **⌘Tab 切回应用后按 Esc** / **右键 Dock 图标 → 关闭鼠标穿透** / 托盘菜单；穿透期间窗口内会常驻黄色提示条写明这些方法） |
| **会议模式** | **⌥⇧M**（可改键），或托盘/右键菜单：一键隐身 + 防录屏 + 提醒静默 + 菜单栏文字清空（共享屏幕连菜单栏一起被录）；散会再按一次，恢复进会前状态并展示错过的提醒 |
| 显示/隐藏股票代码 | 默认隐藏（隐蔽优先）；右键空白处 → 显示股票代码，或设置 → 外观 → 显示股票代码；需要临时核对时**按住 ⌥ 键**即可，松开恢复 |
| **快捷键复位** | 设置 → 行为 → 全局快捷键 → **恢复默认快捷键**（改乱了随时一键回退） |
| 静默优先 | 变动脉冲默认关闭（办公室里红绿闪烁太显眼）；想要动效去设置 → 外观 → 变动脉冲开启 |
| 背景浓度 | 眼睛图标滑杆，或 ⌥⇧↑ / ⌥⇧↓（35%–100%） |

所有快捷键可在设置中重新录制；与其他应用冲突时会弹提示。所有可视操作均有对应的界面按钮，不依赖快捷键记忆。

## 开发

```bash
npm test           # 核心层单元测试（解析/时段/备源滞回/提醒口径/多屏容差等）
npm run lint       # 语法门禁（src/tools/tests 全量 node --check）
npm run smoke      # 冒烟自检：真实拉数据 + 自动截图（--smoke 独立 profile，不污染日常配置）
npm run icon       # 重新生成托盘图标（纯 Node，无依赖）
WIDGET_DEV=1 npm start   # 打开 DevTools 调试渲染层
```

打包（需要时）：

```bash
npm install --save-dev electron-builder
npm run dist       # 产出 dist/ 下 arm64 + x64 双 dmg；Dock 显隐由应用内设置控制
```

## 架构

```
src/
├─ main/            # Electron 主进程
│  ├─ index.js      # 生命周期 · 接线（尺寸/隐蔽状态机在此装配）
│  ├─ window-sizing.js # 尺寸自适应 · 迷你条 · 弹层监视 · 边缘缩放会话
│  ├─ stealth.js    # 隐蔽状态机：老板键 · 会议模式 · 静默累积 · 防录屏 · Dock 联动
│  ├─ migrations.js # 配置迁移（布尔标记 + schemaVersion 迁移表）
│  ├─ window.js     # 主窗（透明分离置顶穿透位置记忆）+ 设置窗
│  ├─ login-window.js  # 扫码登录窗（独立 partition，探测式登录确认）
│  ├─ orchestrator.js  # 轮询状态机：备源切换 · 时段感知 · 快照 · 三分类失败 · 隐藏暂停
│  ├─ smoke.js      # 冒烟（拉数据 + 截图 + 退出）
│  ├─ tray.js / shortcuts.js / ipc.js / toast.js / logger.js / preload.js
├─ core/            # 零 Electron 依赖（可单测）
│  ├─ market/       # quote(东财) · tencent(备源) · search · trends · news
│  ├─ sync/myfavor.js  # 云端自选 API（分组列表 + 组内股票）
│  ├─ code-parser.js   # 全写法代码解析（A股/指数/ETF/北交所/港美股）
│  ├─ session.js       # 交易时段状态机（A/H/US，含美股跨夜宽窗口）
│  └─ retry.js
├─ store/settings.js   # 原子写 + 双备份回滚 + 写入时归一化 + 防抖写
├─ renderer/        # 主窗 + 设置窗（无框架，零网络请求，全走 IPC）
└─ shared/          # constants（端点）· bounds（多屏位置校验，纯函数）
```

设计原则：网络与凭据全部收在主进程；渲染层零请求、零 Cookie 接触；云端自选**只读**（不在应用内增删云端，避免误覆盖手机端列表）。

## 可靠性设计

- **备源**：东财主源同一 tick 内先快速重试（300ms/900ms）；连续 3 次失败才切腾讯（qt.gtimg.cn）。
  切到备源后至少停 60s 不回头，之后才探活主源，且**连续 2 次探活成功**才切回；探活不通过则退避翻倍（60s→120s→…→10 分钟上限）。
  切回后还有 5 分钟观察期，期内再失败 1 次直接退回备源——这样就不会再出现"十几秒横跳一次、每次弹网络异常"。
- **时段感知**：竞价 / 连续竞价 / 午休 / 收盘 / 非交易日各用不同刷新频率；收盘后降为 15 分钟低频心跳（15:00–15:10 保持 60s，保证 15:05 战报准时）；可选「隐藏超 5 分钟暂停轮询」；连续无变化自动降速（替代写死节假日表，自纠错）；**美股跨夜宽窗口**：北京周六凌晨（= 美股周五晚盘）照常交易中
- **失败三分类**：网络错误（退避重试）/ 登录过期（黄条 + 重扫按钮）/ 接口变更（通知 + 手动模式兜底），不会一律黄点
- **快照**：最后一份行情与自选本地留存，断网 / 崩溃重启后先恢复界面再拉新
- **分时双源**：分时图先请东财（同轮内重试 3 次），仍失败自动切腾讯分钟线，均价按 VWAP 还原；两个源都挂才提示失败
- **存储**：写临时文件 + rename 原子落盘，保留 .bak 滚动备份，损坏自动回滚
- **日志**：按天滚动 7 天，Cookie / 凭据强制脱敏

## 已实测的接口（2026-10-12）

| 用途 | 端点 | 备注 |
|---|---|---|
| 批量行情 | `push2.eastmoney.com/api/qt/ulist/get` | ⚠️ `ulist.np` 已失效；必须带 `pn/pz/po/np/fid`，否则 rc:102。⚠️ 2026-10-14 实测该接口有**时间窗式风控**：好窗口连续 200、坏窗口连续空响应（TLS 握手正常后对端直接断，curl 52 / `ERR_EMPTY_RESPONSE`），实测成功率 20%–60% 且随时间波动（同一时刻腾讯 10/10、东财 searchapi/np-listapi 均正常，push2 根路径 404 说明 CDN 是活的）。因此本轮改为**一次请求拉全**（`pz` = 本次条数，385 只 = 1 个请求，实测能完整返回 385 条），并配主源滞回 |
| 搜索 | `searchapi.eastmoney.com/api/suggest/get` | |
| 分时 | `push2his.eastmoney.com/api/qt/stock/trends2/get` | ⚠️ 与批量行情同源同风控（同样的时间窗式空响应），已加单轮重试 3 次 |
| 分时备源 | `web.ifzq.gtimg.cn/appstock/app/minute/query?code=` | 腾讯分钟线，实测 10/10 可用；行格式 `时间 现价 累计量(手) 累计额(元)`，均价用 VWAP=额/(量×100) 还原（与东财均价线口径一致，实测 1277.11 vs 1277.117） |
| 快讯 | `np-listapi.eastmoney.com/.../getNewsByColumns` | 必须带 `req_trace` |
| 云端自选 | `myfavor.eastmoney.com/v4/webouter/*` | 纯 Cookie + 固定 appkey；**必须带 cb 回调参数**（否则空 body）；**必须带 Referer**，且只能通过 `onBeforeSendHeaders` 注入（`referrer` 选项不生效、手动 `setHeader` 会被 Chromium 取消）；security 字段真实格式为 `市场号$代码$时间戳` |
| 备源行情 | `qt.gtimg.cn/q=` | GBK 编码 |

所有请求 UA / Referer 对齐东财网页版自身。接口参数以 `src/shared/constants.js` 为准，变更时只需改常量与对应适配器。
