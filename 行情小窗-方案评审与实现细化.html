总评

v1 方案的技术选型与前期功课是扎实的：Electron 选型正确、接口逆向深入、凭据安全设计专业。但按「美观、易用、舒适、可靠」四个标准逐面审，存在 1 处必须修正的技术缺陷与 19 处可优化点——集中在三件事上：异常态没有设计、视觉规范没有落地、兜底入口不全。

先说结论：方向对、骨架好，值得做。v1 已经回答了「能不能实现」（能，接口已实测）；v2 要回答的是「做完之后好不好用、出事了怎么办」。这个差别正是本次评审的全部重点。

01 / P0 · Must Fix

必须修正：透明度的实现方式

v1 用 win.setOpacity() 做「透明度滑杆 15%–100%」。这是整份方案里唯一必须推翻重来的决策：它让整个窗口（包括文字）一起变淡，15% 时数字完全不可读。「背景隐蔽」和「看清数字」在这条路上是互斥的——而这恰恰是产品的两个核心诉求。

窗口透明度可调 → win.setOpacity()，一个滑杆 15%~100% v1 方案 · 原文

setOpacity() 作用于 OS 层的整个窗口合成——背景板、文字、按钮一视同仁。拖到 40% 以下，价格数字就开始糊；拖到 15%（v1 的下限），小窗基本等于消失。用户真正想要的是：背景板尽可能透明，数字始终清晰。这是两个独立的自由度，必须分开实现。

修订方案：背景与文字分离

窗口本体用 transparent: true + backgroundColor: '#00000000' 创建，透明度滑杆只调内容区背景板的 alpha 通道（CSS rgba()），文字的不透明度恒为 1。两个滑杆拖到同样的低值，观感天差之别：

左侧模拟 setOpacity()：文字与背景一同变淡，<40% 即难以阅读。右侧模拟修订方案：仅背景板 alpha 变化，0% 时只剩文字悬浮于桌面，依然可读。

再进一档：原生毛玻璃。在背景板 alpha 之外叠加 Electron 的 vibrancy: 'under-window'（macOS 原生 NSVisualEffectView），获得系统级毛玻璃质感——与 macOS 自带的小组件、控制中心观感一致，比纯色半透明更融入桌面。设置中提供「毛玻璃 / 纯色半透明」二选一（部分壁纸下纯色可读性更好）。配套调整：原方案的 ⌥⇧↑/↓ 快捷键语义改为「背景浓度 ±5%」，而非整窗透明度。

这一处修正同时改善了美观（质感）、易用（低透明度下仍可读）与体验（隐蔽与看清不再两难），是全文优先级最高的一项。

02 / Reliability

功能可靠：把「能通」升级为「出事也不倒」

v1 的可靠性设计止步于「Cookie 过期挂黄点」。但一个 7×24 常驻的工具，真正的考验全在异常态：接口挂了、网断了、进程崩了、配置写坏了。可靠性的本体不是主流程，是异常分支。

2.1数据链路：单源、盲刷、精度

问题一：单点数据源。v1 全部押在东财非官方接口上。行情接口虽多年稳定，但「多年稳定」≠「永远稳定」。修订：新浪行情备源（qt.gtimg.cn/q=sh600519,sz000001，字段以 ~ 分隔，同样无需登录、同样久经考验）自动降级——主源连续 3 次失败切换备源，主源每 60 秒探活、恢复自动切回，状态条标注当前数据源。用户对切换无感知，最多看到一行小字。

问题二：无交易时段感知。固定 3 秒刷新意味着收盘后、周末、节假日仍在以 3 秒频率请求——既浪费又徒增风控暴露面，状态条还永远显示「最新」。修订：刷新频率由交易时段状态机驱动：

问题三：精度与容错细节。东财行情接口在不带 fltt=2 时返回的 f2（现价）是放大后的整数，需要按市场规则手工除算——这是社区项目里最常踩的坑。修订：请求统一带 fltt=2 直接取浮点；停牌股票 f2 返回字符串 "-"，解析层显式容错（进入「停牌」态，见 §5.3）；自选超过 50 只时自动分批请求，避免单请求过载。

问题四：请求身份。裸请求的默认 UA 与浏览器差异明显，是被风控识别的常见诱因。修订：所有请求的 UA / Referer 对齐东财网页版自身，行为与一个开着网页的浏览器无异。

2.2同步链路：失败要分类，不能一律黄点

v1 对云端自选同步的失败处理只有一种：「挂黄点」。但失败至少有三类，处理方式完全不同——未登录（Cookie 过期，需要重扫）、网络错误（等网络恢复，退避重试）、接口变更（东财改了协议，重试无意义，需要通知用户切手动模式）。一律黄点会让用户在断网时误以为登录过期，白白扫码。

修订：三分类失败处理＋指数退避（1 s / 2 s / 4 s，连续 5 次后转 60 s 慢速）＋快照兜底（最后一份自选列表与行情本地留存，离线 / 失败期间照常显示，仅标注数据时间）。另外补一块 v1 完全没提的：云端分组——东财自选支持多分组，若用户手机上分了「长线 / 短线」，单列表混排会乱。修订：云端分组映射为小窗顶部的分组 tab，默认「全部」合并视图。该数据服务的接口契约已于 2026-10-12 静态逆向确认并在游客态实测存活（详见 §6.4）——无加密参数，v1 担心的 dtoken 风险排除。

2.3进程与数据：崩溃、断电、日志

四个 v1 未提、但常驻工具必备的底盘：

崩溃恢复——渲染进程 crash 事件监听，自动重建窗口（用户最多看到一次闪烁）；requestSingleInstanceLock 单实例锁，防止误开两个。配置原子写——设置与自选列表先写临时文件再 rename，保留双份滚动备份，损坏自动回滚上一版；断电、强退不会丢配置。日志——electron-log 滚动保留 7 天，Cookie 与手机号强制脱敏；出问题有据可查，而不是靠复现。性能预算——摸鱼场景的特殊约束：风扇狂转、电脑发烫本身就是暴露。预算：休市空闲 CPU 趋近 0%、无网络活动；盘中 20 只自选 5 s 刷新 CPU < 2%、常驻内存 < 300 MB；所有动效只走 transform / opacity，不触发布局重排。

03 / Visual

界面美观：从信息草图到视觉规范

v1 的界面草图只解决了「放什么」，没解决「长什么样」。美观不靠灵感，靠把规范定死：字体、数字、颜色、动效每一项都有明确答案，写代码时照表执行即可。

三个最影响观感的点展开说。等宽数字：行情界面的数字每 3 秒变一次，非等宽字体的「1」比「8」窄，价格跳动时整列左右抽动——开关 tabular-nums 一行代码，观感差异巨大。主题：跟随系统深浅色自动切换，可手动锁定；默认深色（该产品的典型使用场景是暗色调的办公室桌面）。动效：价格变动做单次脉冲（背景色淡入淡出一次）而非持续闪烁——持续闪烁在余光里非常恼人，这是很多行情软件被诟病的细节；0.00% 不触发。

3.2修订后的界面结构

在 v1 草图基础上细化：明确的四段式（拖拽头 / 指数条 / 列表 / 状态条）、右对齐的价格与涨跌幅列、行内分时展开。状态条是新增的关键段——同步状态、数据源、更新时间都在这里，异常提示（黄条）也出现在这里，用户永远知道「我现在看的数据是什么状态」。

04 / Usability

使用方便：兜底入口与高频操作

易用性的判断标准不是主流程顺不顺（v1 主流程是顺的），而是边缘情况有没有出路：忘记快捷键怎么办、想加一只股票要几步、换个顺序顺不顺手。

4.1托盘：穿透与隐身后的生命线

v1 开启鼠标穿透后，窗口不再响应任何点击，唯一出口是快捷键 ⌥⇧X。用户一旦忘记这个组合键，应用就「锁死」了——看得见、点不着、关不掉。修订：托盘菜单是永远可达的完整功能入口，与快捷键双通道冗余：

4.2手动模式升级：应用内搜索添加

v1 手动模式只有「粘贴 / 文件导入」——加一只股票要切去东财查代码、复制、切回来粘贴，四步。修订：接入东财搜索建议接口（网页版搜索框同源），在小窗内直接输入「茅台」「moutai」「600519」均可实时联想、回车即加，一步完成。粘贴与 .ebk / txt 文件导入保留为批量通道。搜索是手动模式体验的分水岭——它把「手动模式是二等公民」变成了「不登录也挺好用」，同时是云同步接口万一失效时的体验安全网。

4.3高频操作补全

拖拽排序：自选顺序是高频调整项，HTML5 原生拖拽 + 排序即时持久化；云端模式下本地排序覆盖云端顺序（仅顺序，增删以云端为准）。右键菜单：复制代码 / 在东财打开（调系统浏览器）/ 置顶 / 移入分组 / 删除。快捷键全面可自定义：⌥⇧ 系列默认值保留，但全部可在设置中改绑；注册失败（与其他应用冲突）时立即弹提示引导改键，而不是静默失效。点击行为：单击行原地展开分时（图 3-1），再点收起——小窗没有「详情页」概念，避免页面跳转破坏悬浮定位。

05 / Comfort

体验舒适：首启、形态分级与状态全景

舒适 = 用户在任何时刻都知道发生了什么、下一步能做什么，且不被打扰。v1 定义了正常态，这里补齐其余所有时刻。

5.1首次启动：30 秒 onboarding

首次打开是一个空窗口——v1 没有回答这一刻。修订：三步引导，选模式（手动 / 云端，各配一句说明）→ 加自选（搜索框 + 预置示例组合「上证指数 + 沪深 300ETF + 贵州茅台」一键试用）→ 调外观（主题 / 字号 / 背景浓度三个滑杆即时预览）。全程 ≤ 30 秒，任何一步都可跳过。空列表态显示引导文案而非空白。

5.2形态分级：老板键不一定等于消失

v1 的老板键（⌥⇧H）语义是「完全隐藏」。修订为四级形态连续体：完整 → 低调（背景浓度降至 0.35 + 字号降一档）→ 迷你条（双击标题栏收成一行细条）→ 菜单栏（窗口完全退场，菜单栏保留「沪 3809 -0.12%」小字）。老板键默认行为改为切到菜单栏形态——比彻底消失更实用：注意力离开屏幕的几秒里仍能瞄到指数，「完全隐藏」作为可选配置保留。再进一步，「伪装模式」（显示为一段代码 / 笔记的静态截图）列入二期。

6.5安全设计（v1 保留 + 三项补充）

v1 的四条原则全部保留：全程扫码不触密码、Cookie 经 safeStorage 加密本地存储、请求硬编码只发 *.eastmoney.com 域、过期不静默失败。补充三项：日志强制脱敏（Cookie、手机号、uid 永不入日志）；UA / Referer 对齐网页版（降低风控误伤，也避免特征暴露）；只读原则——应用对云端自选只读同步，不在应用内提供增删云端自选的操作（避免误同步覆盖手机端的列表；本地增删仅作用于手动模式）。备源仅访问 qt.gtimg.cn 一个只读端点，域名白名单相应扩展。
